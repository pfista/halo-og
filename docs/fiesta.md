# Fiesta starting equipment

In **Multiplayer → Edit Gametypes → select a game type → Item Options →
Starting Equipment**, choose **Fiesta** alongside the existing **Custom** and
**Generic** choices. Finish **Save Changes**, then select that game type for
your match. The existing default starting equipment stays unchanged.

Each spawn receives two different random weapons from the original Xbox pool:
assault rifle, pistol, plasma pistol, plasma rifle, needler, shotgun, sniper
rifle and rocket launcher. A fresh pair is chosen each time; weapons retain
the loaded map's original ammo, charge and weapon behavior. Added community
weapons, objective items and vehicles are excluded.

The map's **Weapon Set** still controls world pickups. Fiesta starting weapons
are selected independently, including with Pistols or Rockets selected. The
existing grenade rules, including Infinite Grenades, remain in effect.
If a custom map lacks enough original weapons, or a new pair cannot be created,
the player retains their normal starting equipment.

Fiesta works with the existing multiplayer game modes. It is selected before
the match and cannot be changed through the pause Performance Options page.
Performance presets and other settings preserve it. Copy, rename, save-as and
reload use the existing signed game-type format.

The host chooses and creates each pair; joining clients receive the resulting
inventory. Every player must use a build that supports Fiesta before the host
can start or admit them to a Fiesta match. Clients also require the host's
capability acknowledgement before applying the saved rule.

Production-function fixtures exercise the menu callbacks, saved game types,
ordered weapon pairs, host/client gating, placement remapping, equipment
replacement and failure recovery. These fixtures do not establish live
cross-platform multiplayer behavior or subjective gameplay feel.
